## 📖 Overview

**IoT LAB** is a curated collection of **22+ real-world IoT and Embedded Systems projects** built using **Arduino Uno, ESP32, and ESP8266**.

This repository focuses on hands-on learning through practical implementations in:

- 🏠 Home Automation & Smart Devices
- 🩺 Health Monitoring & Biomedical Systems
- 🌱 Smart Agriculture & Plant Care
- 📡 Robotics, Radar & Automation Systems
- 🔋 Battery Health & Power Monitoring
- 🧠 Sensor-Based Intelligent Systems
- 📡 Wi-Fi & Communication Systems

The goal is to bridge the gap between **hardware and software integration** using structured, real-time applications.

# ▶️ How to Run the Projects

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/lshariprasad/IoT-LAB.git
```

## 2️⃣ Open Arduino IDE

1. Connect your Arduino Uno / ESP32 / ESP8266
2. Open the desired project folder
3. Select correct Board (`Tools` → `Board`)
4. Select correct Port (`Tools` → `Port`)
5. Click **Upload**

## 3️⃣ Monitor Output

6. Open **Serial Monitor** (`Tools` → `Serial Monitor`)
7. Set correct baud rate (usually `9600` or `115200`)
8. Observe LEDs, sensors, motors, or web interface (depending on project)
